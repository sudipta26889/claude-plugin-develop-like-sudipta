> **Mode:** A (greenfield phased) — driving CC against the plugin's own repo.
> **Budget:** unbounded; stops on `job_complete`, `monitor.stop`, or user explicit halt.
> **Goal:** Close the four drift gaps surfaced by the v5.0.3 post-ship survey.

## Survey findings (pre-flight)

1. `CLAUDE.md:13` says `(currently 5.0.1)`; actual is 5.0.3. Drift from the v5.0.2 + v5.0.3 ships.
2. `ccbridge_status.sh` doesn't know about `unblock_cc.sh` (added in v5.0.2 BUG-4 fix). Health check undercounts bridge scripts.
3. `cc-resume.md` slash command doc has no pointer to the v5.0.3 no-sleep doctrine — a resumed session would have the doctrine in SKILL.md but the command instructions wouldn't reinforce it.
4. Pre-commit hook `check_no_hardcoded_paths.sh` scans `commands/`, `skills/`, `evals/` but NOT `hooks/scripts/` itself. The hook can't catch a hardcoded path in its own neighbor scripts.
